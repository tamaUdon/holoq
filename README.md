### Prerequisite
- Python >=3.11
- uv (推奨)

### Install

```
# uv が入っていなければインストール
$ pip install uv

# 依存関係のインストール
$ uv sync
```

### Get Started

```
# 点群法のサンプルコードを実行する
$ uv run python ./sample/pointcloud.py
```
